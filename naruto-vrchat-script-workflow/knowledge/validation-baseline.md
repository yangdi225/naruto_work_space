## 使用方式

这份报告不是要求一次性重写全部旧稿。它用于证明 V2 校验器能拦截旧工作流的已知问题。以后新脚本必须做到：硬错误为 0、时间轴与标称时长一致、人工反馈未完成前不进入 `shoot_ready`。

## V3 增量校验

标记 `工作流版本：V3` 的新脚本还会检查：

- 第一次主动权转移必须在前 5 句。
- 第二个新信息、最强包袱和峰后口播数必须填写有效台词序号。
- 最强包袱必须位于最后 25% 的口播中。
- 最强包袱之后最多保留 1 句口播，且声明值必须与实际行数一致。
- 中段删除测试必须通过。
- 扩写回归只能是 `expanded_clean` 或 `cold_open_wins`。

`tests/fixtures/validator-v3-valid.md` 用于确认合格 V3 稿通过；`validator-v3-invalid.md` 覆盖峰值过早、峰后解释过多、第二信息越界和扩写失败。旧脚本没有 V3 标记时不会被追溯应用这些规则。
