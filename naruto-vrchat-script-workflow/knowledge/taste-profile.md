# 喜剧口味画像 V1

本文件记录用户真实选择，不记录生成器自评。生成候选、扩写和盲审时优先读取；单次反馈只形成暂定假设，至少两次独立选择才升级为稳定偏好。

## 稳定偏好

### TP00 可持续升级的荒唐事件

- 表现：角色先把原著关系、能力或物件作出错误且具体的字面执行，再以至少两次主动行为把麻烦越搞越大。
- 证据：用户明确认为 S004、S006、S007 的整体效果好；三条分别依赖带土抢嘴遁流程、佐良娜翻父亲档案、鸣人把守鹤本体当娃娃带回家，均不是单句反转。
- 使用：默认先写完整事件版，再决定是否剪短；公式只能标注，不能决定题目。

### TP01 黑色旧账反压

- 表现：角色先占据解释权或身份高位，随后被自己的原著旧账堵回去。
- 证据：校准 R001 中 B、C、D、F 获得正向评价；四项都包含身份矛盾或危险关系反压。
- 使用：优先让旧账改变当前主动权，不把旧账当作单纯台词彩蛋。

### TP02 连续信息翻面

- 表现：危险悬念之后，至少两个新事实连续改变观众理解。
- 证据：扩写 R002 中，用户选择“我试过了 -> 鸣人仍活着 -> 亲戚本来挺多”的 B 版。
- 使用：第二层信息必须升级第一层，不能换一种说法重复前提。

### TP03 身份或关系受损

- 表现：包袱击中角色的尊严、身份可信度、亲密关系或原著选择。
- 证据：R001 的正向候选分别击中鼬的灭族旧账、卡卡西的慰灵碑旧账、大蛇丸的永生信用和迪达拉的艺术观众问题。
- 使用：小事可以做入口，但代价必须落到角色身份或关系。

## 稳定反偏好

### TA01 低损失可爱冲突

- 表现：角色只是拌嘴，没有秘密、尊严、关系或行动自由受到威胁。
- 证据：R001-A 被评价无聊。

### TA02 从开头可预测的处罚

- 表现：角色一开始就知道会挨打，后续只是在确认同一个结果。
- 证据：R001-E 被评价无聊。

### TA03 结构合格但没有新处境

- 表现：中段连续问答，却没有新信息或主动权变化。
- 证据：S012 硬质检通过但被评价无聊。

## 暂定假设

### TH00 过度短格式化会压扁喜剧

- 当前证据：S014-S016 连续出现“结构合格但用户感到无聊或奇怪”的反馈；用户明确指出新脚本一条比一条烂，而早期 S004、S006、S007 更好。
- 失败表现：30 秒、双人、单线、固定峰值和台词契约被当作创作目标，角色只解释答案，缺少能持续升级的荒唐行动。
- 使用：V4 默认写 60-90 秒完整事件版；短版只从完整事件剪出。质检不再以固定翻面位置或高分自评作为趣味证据。
- 升级条件：下一批至少 3 条 V4 完整事件版获得人工评价后复盘。

### TH04 无因果升级会显得莫名其妙

- 当前证据：用户评价 S017 中“学生翻窗”莫名其妙。
- 失败表现：佐助说“自己选路”后，学生突然翻二楼窗户；这一行动既非角色合理下一步，也不由忍术、现场规则或既有信息逼出，只是为了满足“第二次升级”。
- 使用：故事红队逐步写明“谁为什么做下一步”；任何关键动作无法给出人物动机时，整条重建，不用补台词硬救。
- 升级条件：再出现一次同类反馈后升级为稳定反偏好。

### TH01 最强包袱后的解释会泄气

- 当前证据：S013 的创作复盘认为“亲戚本来挺多”之后三句存在稀释风险，尚无用户最终选择。
- 使用：默认把最强包袱放在最后 25%，之后最多保留一句短台词或一个无台词动作。
- 升级条件：获得至少一次结尾 A/B 人工选择或真实完播数据支持。

### TH02 情绪反转不等于喜剧反转

- 当前证据：S014 结构完整、信息翻面和峰值位置均通过，但用户评价“无聊”。
- 失败表现：最强句“你根本没在等我”更像关系控诉或严肃同人台词，没有具体荒唐行为导致角色丢脸。
- 使用：最强包袱必须回答“谁因为哪件荒唐行为丢脸”；只有伤感、锋利或正确，不得晋级。
- 升级条件：再出现一次同类人工负反馈后升级为稳定反偏好。

### TH03 凭空视觉化会破坏原著因果

- 当前证据：S015 被评价“莫名奇妙”。
- 失败表现：把不尸转生直接改写成“旧身体挂衣架”，没有原设定或当前场景因果；“先把自己穿明白”依赖作者双关，不像佐助会说的话。
- 使用：关键道具或动作必须由原著能力必然导出，或先用一句角色化台词建立它为什么存在；结尾双关必须通过角色口吻测试。
- 升级条件：再出现一次同类人工负反馈后升级为稳定反偏好。

## 默认生成倾向

- 优先关系：兄弟、宿敌、师徒、组织搭档、危险合作关系。
- 优先结构：异常行为 -> 危险悬念 -> 原著事实翻面 -> 身份旧账封口。
- 优先表演：停顿、移开视线、抢走道具、后退、解除忍术。
- 降低优先级：萌系误会、普通挨打、流程处罚、功能说明、完整复述原著。

## 更新规则

- 用户四标签反馈为：`保留`、`一般`、`无聊`、`奇怪`。
- `保留`：增加相关模式置信度。
- `一般`：不改变稳定偏好，记录最可能的泄气点。
- `无聊`：记录缺少欲望、损失、新信息或不可预测性中的主因。
- `奇怪`：记录角色动机、时期关系、因果或口吻中的主因。
- 每累计 5 条人工评价复盘一次；没有真实评价时不推断新偏好。
