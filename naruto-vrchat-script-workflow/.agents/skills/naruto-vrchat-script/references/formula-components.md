# 公式组件系统 V2

## 目的

旧版 F001-F014 是可复用的完整配方，但一次叠加多个完整配方容易让脚本像在完成检查表。V2 把公式拆成三个维度，每条脚本默认各选一个：

`冲突引擎 Cxx + 火影载体 Nxx + 收尾机制 Pxx`

旧 F 编号继续保留，用于追踪来源和历史效果，不再要求每条脚本叠加多个 F 公式。

## 冲突引擎

### C01 追责审判
- 起点：一个角色拿着明确问题质问另一个角色。
- 推进：被质问者先否认，再重新定义自己的行为。
- 适合：师徒、上下级、队友、组织成员。

### C02 认知错位
- 起点：双方以为正在讨论同一件事。
- 推进：每次回答都让误解更深，直到关键词揭底。
- 适合：经验、制度或时代不同的角色。

### C03 身份倒压
- 起点：弱势方用传统、规则或资历占理。
- 推进：强势方把同一套逻辑升级到更高身份，迫使对方后退。
- 适合：火影/族长、老师/学生、首领/成员。

### C04 资源滥用
- 起点：珍贵能力、忍具或通灵伙伴出现异常损耗。
- 推进：用途越查越小，代价越查越大。
- 适合：能力拥有者与懂行者。

### C05 旧账重审
- 起点：角色带着正当理由重提原著旧事。
- 推进：对方补充被忽略的现场细节，让立场反转。
- 适合：兄弟、宿敌、师徒、父子。

## 火影载体

### N01 忍术或血继限界
冲突必须依赖具体能力才能成立，例如影分身的信息回流、写轮眼消耗、通灵契约或尾兽关系。

### N02 强关系旧账
冲突来自观众熟悉的羁绊、背叛、训练、复仇或家庭关系，去掉角色姓名后不能完全成立。

### N03 忍界组织规则
使用任务等级、忍者学校、家族传统、晓组织目标或村子责任。现实流程词只能辅助，不能成为主梗。

### N04 原著名场面偏移
从一个观众熟悉的场面切入，只改现场理解或遗漏细节，不复述剧情。

### N05 忍界日常小事
把吃饭、训练、取材、养伤等小事与忍术代价直接相撞，笑点仍由火影能力或关系完成。

## 收尾机制

### P01 证据回旋
证据没有证明原罪，而是让质问者或证人暴露新问题。

### P02 关键词揭底
最后一句揭示双方一直理解错了同一个词。

### P03 第三人一刀
第三人只在关键时刻出现一次，补充决定性事实后结束，不继续展开支线。

### P04 动机翻面
看似离谱的行为其实有一个符合角色关系的动机，但这个动机又暴露更荒唐的代价。

### P05 代价即时到账
忍术、契约、体力或关系代价在最后一刻直接落到当事人身上，用动作而不是解释收尾。

## 组合规则

- 默认只选 1 个 C、1 个 N、1 个 P。
- 先写一句话冲突，再选择组件；不要为了使用组件反向拼题。
- 两条候选如果只更换角色名仍然成立，说明 N 组件不够强。
- P03 的第三人不能再引出第二条冲突线。
- 旧 F 公式作为 `legacy_formula` 记录来源，不参与堆叠计数。
