# 对标文案拆解规则 V1

## 拆解目标
拆的是结构，不是抄内容。最终要把对标文案变成可迁移到火影 VRChat 的冲突公式。

## 输入处理

如果用户提供的是完整文案：

- 保留关键句。
- 标记每句承担的功能。
- 不逐字复写长文本。

如果用户提供的是视频描述：

- 先还原可能的内容结构。
- 明确哪些是推测。
- 再提炼可迁移公式。

## 必拆模块

1. 3 秒钩子：第一句如何制造好奇、冲突或荒诞。
2. 人物关系：谁压谁、谁求谁、谁拆谁台。
3. 表层事件：观众听到的具体事情。
4. 深层冲突：身份、利益、面子、规则、情感或能力的矛盾。
5. 升级路径：每 5-10 秒冲突如何变强。
6. 笑点机制：误会、错位、反差、重复、补刀、反客为主。
7. 反转：最后谁被打脸，或问题如何换了性质。
8. 可迁移点：能迁移成哪个火影角色关系。
9. 不可迁移点：过度现实、过度平台、过度地域或难拍元素。

## 迁移到火影 VRChat 的原则

- 现实里的老板员工，可以迁移为火影和下忍、晓组织首领和成员、老师和学生。
- 现实里的报销绩效，可以迁移为任务等级、忍具预算、村规、晓组织经费。
- 现实里的情侣拉扯，谨慎迁移，优先转成队友羁绊或师徒甩锅。
- 现实里的炫富炫技，可以迁移为血继限界、尾兽、万花筒、禁术。
- 现实里的社死，可以迁移为任务翻车、忍术误用、身份暴露。

## 判定好公式的标准

- 一句话能讲清冲突。
- 换一组角色仍能成立。
- 能自然接入原著设定。
- 能用 1 个场景、2-4 个角色拍完。
- 有明确反转，不靠硬尬结尾。

## 禁止事项

- 不把对标文案逐字改名。
- 不输出只有“很搞笑、节奏快”的空泛评价。
- 不把火影写成讲解素材。
- 不为了套梗牺牲角色关系。
