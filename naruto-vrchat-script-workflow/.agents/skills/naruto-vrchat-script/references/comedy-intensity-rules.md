# 喜剧强度门槛 V2

## 目的

硬质检只能判断格式和拍摄结构是否成立，不能判断好不好笑。候选进入冷开场前，先检查角色欲望、损失、羞耻和新信息；逻辑完整但缺少喜剧压力的题直接淘汰。

## 六个必要问题

1. **角色想要什么**：求生、复仇、保住尊严、偷懒、获得认可、隐瞒真相或避免挨打。不能只想“解释清楚”。
2. **马上会失去什么**：命、面子、关系、身体控制权、秘密或行动自由。损失不能只在结尾口头宣布。
3. **谁最丢脸**：至少有一个角色的自我认知被击穿；没有羞耻目标的争论容易只剩逻辑题。
4. **第二个新信息是什么**：中段必须改变观众对事件的理解，不能只换一种说法重复第一包袱。
5. **主动权是否转移**：前五句内至少发生一次。始终由同一人提问、另一人回答，节奏会变平。
6. **为什么只能是这组角色**：最好笑的一句换给其他角色后应明显失效。

## 一票否决

- 一句话梗概已经包含全部笑点，后面只能解释。
- 冲突双方都没有明确欲望或损失。
- 中段只连续反问、举例或换答案，人物处境没有变坏。
- 结尾在关键词出现时就能被直接猜到。
- 笑点只是忍术功能讨论，没有伤到角色的身份、关系或尊严。
- 需要靠完整分镜、音效或自评分才能显得有趣。

## 20 秒冷开场要求

- 前两句建立欲望和阻力。
- 前五句至少出现一次主动权转移。
- 结束前给出第二个新信息，并留下继续升级的空间。
- 不追求讲完故事；冷开场的任务是让人想听下一句。
- 不能附带推荐答案或自评分，以免影响人工第一反应。

## V3 扩写入口

冷开场进入扩写前还必须满足：

- 至少标出两个新信息所在的台词序号。
- 至少标出一次主动权转移所在的台词序号。
- 能说清最可能被观众提前猜到的结尾。
- 不能靠“后面分镜会更好笑”解释当前台词。

## 校准模式

当最近连续 3 条脚本被用户标记为无聊或奇怪，或用户明确要求校准时：

1. 暂停完整脚本生产。
2. 生成 6 条不同喜剧机制的 15-20 秒冷开场。
3. 不写分镜，不做公式评分，不选冠军，不加入正式选题池。
4. 必填反馈只保留“最想继续看哪条”；最好笑哪句、从哪句开始无聊改为可选。
5. 至少获得一次人工反馈后，再决定保留、改写或淘汰。
