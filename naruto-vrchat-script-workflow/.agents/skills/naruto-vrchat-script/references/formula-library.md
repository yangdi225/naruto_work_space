# 爆款公式库 V1（兼容层）

> F001-F014 保留为历史配方编号。新脚本优先读取 `formula-components.md`，使用“1 个冲突引擎 Cxx + 1 个火影载体 Nxx + 1 个收尾机制 Pxx”；本文件只记录来源、成功经验和兼容映射，不再默认叠加多个 F 公式。

## V2 使用规则

- 先确定一句话冲突，再选择组件，不从公式名称反推剧情。
- 每条脚本最多记录 1 个主要 `legacy_formula`，其他 F 编号只作为参考。
- 最近 10 条脚本中，某个 F 公式使用超过 4 次时，下一批候选降低其优先级。
- F008“旧账证据反杀”已在现有脚本中过度使用，进入冷却；除非用户明确指定，下一批不作为主要公式。
- 公式效果以 `knowledge/script-evaluations.csv` 的人工评价和发布数据为准，不以生成器自评分为准。

## F001 离谱任务审判

- 一句话定义：火影办公室宣布一个离谱任务，角色因身份、能力或历史包袱当场吵起来。
- 适用角色：纲手、卡卡西、鸣人、佐助、小樱、鹿丸。
- 开场钩子：`纲手：这次 S 级任务，是让{角色A}去{荒诞目标}。`
- 冲突推进：任务离谱 -> 角色拒绝 -> 另一人补刀 -> 火影用预算/村规压制。
- 反转模板：真正危险的不是任务，而是某个角色早就把事搞砸了。
- VRChat 拍摄：火影办公桌正反打，纲手拍桌，角色轮流后退。
- 禁用风险：不要变成任务说明书，必须让人吵起来。

## F002 忍术被当成职场工具

- 一句话定义：把原著忍术放进忍界日常管理，制造能力滥用的荒诞感。
- 适用角色：鸣人、卡卡西、鹿丸、影分身相关角色。
- 开场钩子：`鹿丸：谁批准你用影分身代打全村早会的？`
- 冲突推进：能力方便 -> 被滥用 -> 造成责任归属混乱 -> 本尊甩锅失败。
- 反转模板：所有人都以为是影分身偷懒，结果本尊更离谱。
- VRChat 拍摄：同角色分身可用站位替代，镜头切反应特写。
- 禁用风险：不要解释忍术原理，直接演后果。

## F003 晓组织会议内耗

- 一句话定义：晓组织用严肃反派语气讨论很小的组织管理问题。
- 适用角色：佩恩、小南、迪达拉、鼬、带土、鬼鲛、蝎。
- 开场钩子：`小南：本月晓组织最大支出，是迪达拉的爆炸售后。`
- 冲突推进：行政问题 -> 成员嘴硬 -> 理念升华 -> 预算反杀。
- 反转模板：看似最危险的人，其实是唯一按时报销的人。
- VRChat 拍摄：晓基地半圆站位，佩恩居中，小南拿记录本。
- 禁用风险：不要只讲现代公司梗，要把“晓”的目标和能力卷进来。

## F004 第七班家庭会议

- 一句话定义：第七班像问题家庭一样开会，所有小事都被翻成羁绊旧账。
- 适用角色：鸣人、佐助、小樱、卡卡西。
- 开场钩子：`小樱：今天只解决一件事，谁又把任务报告写成复仇宣言？`
- 冲突推进：小事 -> 互怼 -> 卡卡西和稀泥 -> 旧账爆炸。
- 反转模板：最成熟的人最后做出最幼稚行为。
- VRChat 拍摄：训练场三角站位，卡卡西侧边看书，正反打快速切。
- 禁用风险：不要写成恋爱争风吃醋，核心是队友关系和任务逻辑。

## F005 反派理念小题大做

- 一句话定义：反派把日常小问题讲成世界观级痛苦、和平、永恒艺术。
- 适用角色：佩恩、鼬、大蛇丸、带土、斑。
- 开场钩子：`佩恩：一乐拉面少放叉烧，这就是痛苦的起点。`
- 冲突推进：小问题 -> 宏大叙事 -> 众人无语 -> 有人用更小的问题反杀。
- 反转模板：宏大理念最后败给账单、排队、报销、迟到等具体问题。
- VRChat 拍摄：角色特写慢推，旁人反应镜头负责笑点。
- 禁用风险：不要长篇哲学独白，宏大台词要短而荒唐。

## F006 师徒互相甩锅

- 一句话定义：老师和徒弟围绕一次翻车互相证明“不是我教的”。
- 适用角色：自来也/鸣人、卡卡西/第七班、纲手/小樱、大蛇丸/佐助。
- 开场钩子：`纲手：这招是谁教你的？小樱和我只能活一个。`
- 冲突推进：事故出现 -> 徒弟甩师父 -> 师父甩天赋 -> 第三人拿证据。
- 反转模板：证据显示师父和徒弟都没学明白。
- VRChat 拍摄：师徒面对面，第三人从侧面插入证据。
- 禁用风险：不要让师父只讲道理，要有互相拆台。

## F007 原著名场面复盘失败

- 一句话定义：角色试图复刻名场面，但因为 VRChat 或忍界现实条件当场翻车。
- 适用角色：鸣人、佐助、卡卡西、鼬、佩恩。
- 开场钩子：`卡卡西：今天复盘终末之谷，但预算只够一条小溪。`
- 冲突推进：名场面预期 -> 现实条件缩水 -> 角色尊严受损 -> 强行演出。
- 反转模板：缩水版反而暴露角色真正问题。
- VRChat 拍摄：用简单场景替代宏大场面，靠台词和反应完成笑点。
- 禁用风险：不要做原剧情复述，必须复盘失败。

## F008 旧账证据反杀

- 一句话定义：角色带着正当理由来质问或复仇，对方不断拿出 VCR、档案、成绩单、体检报告等证据，把质问者反杀到破防。
- 适用角色：佐助/鼬、佐良娜/鸣人、鸣人/卡卡西、纲手/自来也、博人/鸣人。
- 开场钩子：`佐助：我今天只问一件事，你当年为什么要那样对我？`
- 冲突推进：质问者占理 -> 对方承认一半 -> 拿证据补刀 -> 质问者发现自己也有黑历史。
- 反转模板：质问者本来想审判别人，最后发现最该封档的是自己。
- VRChat 拍摄：正反打质问，第三个镜头给档案袋/VCR/报告特写，结尾给质问者沉默特写。
- 禁用风险：不要变成角色黑历史盘点，证据必须推动现场吵架。

## F009 同词不同义误会升级

- 一句话定义：两个角色围绕同一个词吵半天，最后发现双方理解的根本不是一件事。
- 适用角色：卡卡西/再不斩、鸣人/佐助、鹿丸/丁次、晓组织成员互怼。
- 开场钩子：`卡卡西：你说的“考试杀穿”，是我理解的那个杀穿吗？`
- 冲突推进：关键词出现 -> 双方各自脑补 -> 互相佩服或恐惧 -> 揭露语境错位 -> 全场沉默。
- 反转模板：一个人在说战场，一个人在说考试；一个人在说忍术，一个人在说生活用品。
- VRChat 拍摄：双人对话即可，靠表情从疑惑到震惊升级，最后定格沉默。
- 禁用风险：误会必须早早埋词，结尾揭露才有爽感，不能硬解释。

## F010 神级能力生活化误用

- 一句话定义：角色把写轮眼、尾兽、禁术、须佐、天照等神级能力当成日常工具，逼懂行的人当场崩溃。
- 适用角色：佐助/鼬、鸣人/九尾、我爱罗/守鹤、卡卡西/第七班、大蛇丸/佐助。
- 开场钩子：`鼬：你拿天照烧水？你几个眼睛这么用？`
- 冲突推进：能力异常损耗 -> 被追问用途 -> 日常用途曝光 -> 懂行者破防 -> 误用范围继续扩大。
- 反转模板：原来不止一个能力被误用，另一个更离谱。
- VRChat 拍摄：一问一答正反打，插入手部动作或道具模拟，结尾用反应特写承接笑点。
- 禁用风险：不要解释能力设定太久，重点是“高阶能力被低级用途消耗”的反差。

## F011 预知剧本反向求生

- 一句话定义：角色提前知道原剧情或死亡结局，于是主动认错、销毁证据、改写台词，逼对手失去行动理由。
- 适用角色：团藏/佐助、带土/卡卡西、迪达拉/佐助、大蛇丸/三代。
- 开场钩子：`团藏：剧本上说我今天会死？那我先跪下。`
- 冲突推进：预知结局 -> 主动规避关键台词 -> 对手找理由失败 -> 反派继续加码求生 -> 对手改用更荒诞理由。
- 反转模板：对手最后承认自己不是来讲理的，是专门来找茬的。
- VRChat 拍摄：单场景对峙，剧本作为道具，反派频繁跪下/后退/遮住罪证。
- 禁用风险：不要让“看剧本”变成纯元叙事吐槽，必须落回角色关系和原著旧账。

## F012 家规撞村规

- 一句话定义：家族传统、组织规矩或个人规矩撞上火影政策，被权力话术一步步压成现场认错。
- 适用角色：鸣人/日向长辈、纲手/家族族长、小南/晓组织成员、鹿丸/忍族代表。
- 开场钩子：`鸣人：你说家族传统可以高于木叶政策？`
- 冲突推进：对方搬出传统 -> 主角先顺着说 -> 把话术升级成村规/政策/立场 -> 对方开始后退 -> 结尾暴露主角也心虚。
- 反转模板：主角赢了争论，但承认自己的方法更像恐吓。
- VRChat 拍摄：办公室或族地正反打，主角从温和沟通逐渐前压，对方从强硬到结巴。
- 禁用风险：不要变成现实政策辩论，必须围绕忍族、村规、火影身份和角色关系。

## F013 英雄滤镜档案审判

- 一句话定义：后代、粉丝或新人带着英雄滤镜来质问，知情者用封存档案逐条击碎滤镜。
- 适用角色：佐良娜/鸣人、博人/佐助、木叶新人/卡卡西、晓新人/小南。
- 开场钩子：`佐良娜：我爸是忍者英雄，你们凭什么封他的档案？`
- 冲突推进：后代质问 -> 知情者犹豫 -> 档案逐条公开 -> 英雄滤镜崩塌 -> 真相其实是在保护对方。
- 反转模板：封档不是针对，是为了让当事人还能正常生活。
- VRChat 拍摄：桌面档案袋、角色翻页、听者反应特写，结尾用低声道谢或尴尬沉默收束。
- 禁用风险：不要做履历解说，档案每一条都要引发现场反应。

## F014 真货误当玩具

- 一句话定义：角色想要某个周边、娃娃或道具，强者直接把本体或高危真货带回来，引发多方误会。
- 适用角色：向日葵/鸣人/守鹤、博人/佐助/忍具、木叶孩子/尾兽、砂隐商人/我爱罗。
- 开场钩子：`向日葵：爸爸，我也想要一个守鹤娃娃。`
- 冲突推进：普通需求 -> 强者过度满足 -> 真货伪装成玩具 -> 第三方质疑 -> 商家/原主也懵。
- 反转模板：所有人都以为是高级周边，结果它真的会说话，因为它就是本体。
- VRChat 拍摄：家庭场景或学校门口，玩偶角色站位尽量小幅动作，重点拍孩子炫耀和旁人反应。
- 禁用风险：不要只写炫富，要让“本体被误认成周边”的错位持续升级。
