# 故事先行生产规则 V4

## 核心原则

先写一个角色会真的做出来、而且会不断失控的荒唐事件；公式、时长和镜头都在事件成立后服务它。不能因为一个题能填进 C/N/P 或通过台词序号检查，就把它当作可生产脚本。

## 正向样本

- `S004`：带土为躲卡卡西嘴遁，抢先执行整套认错，又把道歉写成月之眼推广。每次自救都让处境更丢脸。
- `S006`：佐良娜试图替佐助翻案，鹿丸每翻一页档案就让她更难继续维护父亲。档案是持续升级的麻烦来源。
- `S007`：鸣人把“守鹤娃娃”字面理解成守鹤本体，并真的把本体带去学校。误会被行动放大，而不是靠解释收尾。

## 立项门槛

每个选题必须先回答以下五项，缺一项不进入台词：

1. **具体欲望**：主角此刻想得到什么，且为什么非要现在得到？
2. **错误执行**：他把原著能力、关系或物件理解错了什么，并真的采取了行动？
3. **升级阶梯**：至少两次新行动会让现场更糟，而非只是揭露更多背景。
4. **身份代价**：最后谁的火影身份、旧账、尊严或关系被当场损伤？
5. **可见结算**：最后必须有能拍到的状态变化，例如抢走道具、被迫改口、当场露馅或自食其果。

## 时长和结构

- 默认先写 60-90 秒的完整事件版；确认每一段都在升级后，才按需剪成 20-40 秒高密度版。
- 允许 2-4 个主要角色、1-2 个场景。第三人、档案、玩偶、清单等可以使用，但必须改变事件走向。
- 不要求固定句数、固定翻面位置、固定峰值位置或固定 C/N/P 组合。它们只能用于复盘标注，不能倒推创作。
- 每个主要段落必须包含一个新的行动、阻力或可见后果。连续两段只是问答解释时，返回立项重写。
- 升级行动必须是当前角色在已知信息下合理会做的下一步，或由原著能力、明确现场规则直接逼出；不能让旁人突然做危险、愚蠢或便利的动作来替作者升级。

## 反向信号

- 一句话就能解释完整笑点，后续只能重复定义它。
- 角色只是替作者朗读真实答案，没有继续采取荒唐行动。
- 结尾只是一句概念判断，例如“你不是观众，是靶子”，却没有更具体的新处境。
- 为满足短时长，把能够升级的事件和人物反应提前删掉。
- 把一句泛泛建议硬翻译成极端现场行为，例如“独立”就翻窗、 “努力”就自残，而前文没有能力、规则或具体动机支持。

## 交付规则

- 默认交付完整事件版；只有完整事件通过故事红队后，才附一个可选短剪版建议。
- 技术硬质检只负责拍摄时长、镜头、角色和文件完整性；不得用分数或格式契约代替趣味判断。
