# 账号定位 V2

## 账号一句话
用 VRChat 让火影角色在原著设定里当场吵起来，产出高密度、强冲突、快反转的沙雕短视频。

## 内容关键词
火影、VRChat、沙雕短剧、角色互怼、忍界职场、任务翻车、师徒拉扯、组织内耗、原著设定二创。

## 核心观众

- 熟悉火影主要角色和名场面的观众。
- 喜欢短平快沙雕二创的人。
- 喜欢 VRChat 虚拟角色演绎、正反打对话和夸张表情的人。

## 内容边界

必须做：

- 让角色在现场发生矛盾。
- 用原著身份、能力、关系制造笑点。
- 开头 3 秒抛出离谱但清楚的问题。
- 中段让冲突升级。
- 结尾给出反转、补刀或身份错位。
- 让每段台词都能被 VRChat 角色演出来。

不能做：

- 火影剧情解说。
- 严肃设定科普。
- 长篇旁白总结。
- 单纯把现实段子换成火影角色名。
- 角色只站着念稿，没有动作和镜头变化。
- 需要大规模特效或复杂群演才能拍的脚本。

## 标准视频形态

- 时长：默认先产出 45-60 秒测试版；用户明确需要时可扩展到 30-90 秒。
- 人物：2-4 个角色最稳。
- 场景：火影岩、木叶街道、训练场、晓组织基地、火影办公室、一乐拉面、终末之谷等。
- 镜头：正反打为主，插入反应特写、沉默停顿、突然拉近、背影离场。
- 台词：短句优先，一句话一个笑点或推进。
- 分镜：默认 12-18 个；先保证口播时长与时间轴一致。

## 账号语气

- 吵，但不是乱。
- 沙雕，但角色逻辑要成立。
- 离谱，但能用火影设定解释。
- 节奏快，但观众能听清冲突。

## 爆款判断

一个选题是否值得写，先问：

1. 观众能否 3 秒内看懂谁在跟谁吵？
2. 冲突是否来自火影原著关系或能力？
3. 结尾是否有“居然还能这么圆”的反转？
4. VRChat 能否用 2-4 个角色、1 个场景拍完？
