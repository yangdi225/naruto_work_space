# 选题质检规则 V3

## 判断目的

候选判断用于同批排序，不负责预测播放量或证明点子好笑。先执行一票否决，再比较证据；同批候选必须拉开差距。

## 六项证据

| 项目 | 晋级证据 |
|---|---|
| 角色关系压力 | 师徒、兄弟、宿敌、上下级或家庭关系天然存在不能直说的旧账。 |
| 火影专属性 | 去掉角色名后，冲突仍依赖忍术、身份、旧账或忍界规则。 |
| 行为动机 | 角色主动这么做能保护力量、尊严、关系、秘密或行动自由。 |
| 信息升级 | 已明确第二个新信息，且它会改变观众对第一包袱的理解。 |
| 收尾回旋 | 结尾让主动权、身份判断或即时代价发生变化。 |
| 实际可拍性 | 当前库存可用，或有不改变笑点的明确替代。 |

## 库存约束

按 `production-inventory-rules.md` 和 `knowledge/production-inventory.csv` 评分：

- 关键资源为 `unknown` 时只能标记 `inventory_risk`，不能声称可直接拍。
- 关键资源为 `blocked` 且没有替代方案，一票否决。
- 不读取库存表时，不能声称“低成本可直接拍”。

## 结论

- `cold_open`：六项证据成立，可进入匿名冷开场。
- `hold`：核心有潜力，但第二个新信息、角色动机或资源替代尚不明确。
- `reject`：触发一票否决或无法形成第二次翻面。

进入正式脚本还必须在三强冷开场盲审中胜出，并通过一次扩写回归。深度模式才使用四强和两版扩写。

## 一票否决

- 像火影解说标题。
- 主梗是现代行政、平台或热搜流程。
- 角色行为只有“为了完成公式”才能解释。
- 核心冲突需要第五个角色或第二条支线才能成立。
- 关键拍摄资源不可用且没有替代。
- 结尾只能靠解释、写检讨或宣布处理结果。

## 同批规则

- 默认同批 5 个事件候选至少淘汰 3 个；深度模式 12 个候选至少淘汰 8 个。
- 每个晋级候选必须写一个最大风险。
- 人工评价和 `knowledge/taste-profile.md` 优先于生成器解释。
