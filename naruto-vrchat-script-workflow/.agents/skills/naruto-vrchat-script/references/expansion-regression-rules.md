# 扩写损耗检查 V1

## 目的

冷开场胜出后，扩写必须增加新处境，不能把一个有效包袱稀释成完整但平坦的长稿。

## 对照方法

将扩写稿与其冷开场逐项比较：

| 检查项 | 通过条件 |
|---|---|
| 冷开场保留 | 核心异常行为、第一次翻面和角色专属台词仍在。 |
| 新信息增量 | 扩写至少新增一个会改变观众理解的事实。 |
| 主动权变化 | 前 5 句至少一次，全文至少两次。 |
| 中段必要性 | 删除中间三分之一会破坏信息链或主动权变化。 |
| 峰值位置 | 最强包袱位于最后 25% 的口播台词中。 |
| 峰后收束 | 最强包袱后最多一句短台词；优先使用无台词动作。 |
| 解释密度 | 不允许连续两句只解释设定或重复前一句。 |
| 时长服从笑点 | 20-30 秒已经完整时，不为满足默认时长强扩到 45-60 秒。 |

## 删除测试

1. 暂时删除扩写稿中间三分之一台词。
2. 如果开头仍能直接接到结尾，说明中段没有产生新处境，扩写失败。
3. 如果删除一行后节奏更快且信息不损失，该行必须删除或改成动作。

## 预测测试

红队在看到最后四分之一前先写下最可能的结尾：

- 实际结尾与预测同义，且没有角色身份代价：判定可预测。
- 实际结尾只是确认开场威胁：判定没有翻面。
- 结尾反转依赖新角色突然入场：判定结构补丁，除非该角色早有铺垫。

## 结果

- `expanded_clean`：全部通过，可进入正式分镜。
- `trim`：笑点成立但有可删解释句，压缩后复查。
- `cold_open_wins`：扩写弱于冷开场，直接产出较短版本。
- `rebuild`：缺少新信息或主动权变化，返回候选阶段。
