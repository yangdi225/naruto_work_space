# VRChat 拍摄库存规则 V1

## 数据来源

生成选题和脚本前读取 `knowledge/production-inventory.csv`。库存分为：

- `available`：可以直接使用。
- `substitute`：有明确替代方案。
- `unknown`：尚未确认，选题可以候补，但不能判定为低成本可拍。
- `blocked`：当前不可用，包含该关键资源的选题直接淘汰。

## 硬门槛

- 主角 Avatar 必须是 `available` 或 `substitute`。
- 单条正式脚本默认最多 4 个 Avatar、2 个场景、3 个关键道具。
- 关键笑点依赖的模型或道具如果是 `unknown`，VRChat 可拍性最高 14/20。
- 需要复杂合成、多人同屏或大规模忍术特效时，必须写出可执行替代镜头。
- 不能把“理论上能找到模型”当成“当前可拍”。

## 替代原则

- 特效可用音效、出入画和反应镜头替代。
- 小型角色可用低机位 Avatar 或画外音替代，但关键身份必须看得懂。
- 大场景优先改成场后追责，不重演大战。
- 分身优先同机位重复录制，限制为 2-3 个可辨认分身。

## 维护方式

拍摄前把实际拥有的 Avatar、地图、道具和动作更新到库存表，并填写 `last_verified`。超过 90 天未确认的资源按 `unknown` 处理。
