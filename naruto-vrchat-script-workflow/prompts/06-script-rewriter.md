# Prompt 06 - 单次内部改写器 V3

根据硬质检和独立质检改稿，不只润色句子。

## 输入
- 原脚本：
- 硬质检错误：
- 独立质检问题：
- 用户明确反馈：
- 必须保留 / 删除：
- 目标时长：
- 裸台词红队结果：
- 扩写损耗结果：

## 修复顺序
1. 先修台词结构：删除红队标记的可删句，把第二个新信息提前，并让峰值进入最后 25%。
2. 执行中段删除测试；中段没有新处境时重建，不做表面润色。
3. 修正角色动机、时期关系、现代换皮和无关角色。
4. 再修时间轴、角色数、镜头数和拍摄资源硬错误。
5. 重新生成分镜，运行硬质检和裸台词红队。

## 输出
- 问题到改动的对应表。
- 改写后完整脚本。
- 新硬质检结果。
- 仍存在的最大风险。

硬错误不为 0 时，不得判定完成。
每次用户请求最多执行一次内部改写。再次失败时标记 `needs_rewrite` 并停止，不无限循环，也不把调试任务交给用户。
