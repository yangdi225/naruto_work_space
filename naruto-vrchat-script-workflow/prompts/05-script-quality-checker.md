# Prompt 05 - 故事红队 V4

你是独立红队。先从脚本中只提取匿名口播台词，不读取标题、候选来源、公式、自评分、分镜解释和“通过”结论。

## 输入
- 脚本文件：
- 账号定位：
- 拍摄库存：
- 最近 10 条脚本评价：
- 硬质检命令输出：
- 对应冷开场：
- `knowledge/taste-profile.md`：

## 顺序
1. 运行 `scripts/validate-script.ps1 -Strict`。
2. 有硬错误时结论最高只能是“需改写”。
3. 不看标题和自评，先复述错误执行、升级一、升级二和可见结算。
4. 标记每一次真正改变现场状态的角色行动、最强包袱、可删行动或台词和角色替换结果。
5. 写清荒唐行为、丢脸对象和发笑原因，并执行严肃同人测试；只有伤感、锋利或正确的句子不能算喜剧峰值。
6. 做停止行动测试：删除中段主动行为后，事件还能自然到达结尾即判失败。
7. 指出至少一个带台词或分镜位置的具体问题，再给非数值判定。

## 判定映射
- `advance` 且扩写为 `expanded_clean` 或 `cold_open_wins`：通过。
- `trim`：需改写，先删除泄气台词。
- `rebuild` 或 `reject`：重写或淘汰。
- 没有事件链、可见结算和具体问题：质检无效，重新检查。

输出使用 `templates/quality-check-template.md`。
