# Prompt 02 - 公式组件提取器 V2

从对标拆解中提取组件，不直接新增一个包办所有步骤的完整公式。

## 输入
- 对标拆解：
- `references/formula-components.md`：
- `references/formula-library.md`：

## 输出
- 最接近的冲突引擎 Cxx；没有匹配时给新增建议。
- 可迁移的火影载体条件，不直接指定唯一角色。
- 最接近的收尾机制 Pxx。
- 对应旧 F 公式来源。
- 可复用条件、失效条件和拍摄约束。
- 3 个一句话迁移示例。

## 规则
- 新增组件必须能跨角色复用，且与已有组件有实质差异。
- 不因一个案例就新增万能规则。
- 不把固定台词当公式。
- 不叠加多个完整 F 公式证明复杂度。
