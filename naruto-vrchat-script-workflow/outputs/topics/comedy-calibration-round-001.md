# 喜剧校准 Round 001

本轮只测试 15-20 秒冷开场。没有分镜、评分、排名和推荐答案。

## A

```text
鸣人：道歉完了？回来，解除。
影分身：我不解。
鸣人：你是我放出来的！
影分身：可小樱说我比本体懂事。
鸣人：那也是在夸我。
影分身：她还说，本体最好永远别出现。
小樱画外音：鸣人！
影分身：听见没？叫你呢。
```

## B

```text
鼬：你切洋葱干什么？
佐助：开万花筒。
鼬：万花筒靠痛苦，不靠辣眼睛。
佐助：我已经很痛苦了。
鼬：你痛苦的是洋葱。
佐助：至少它没杀我全族。
鼬：刀放下，我们重新聊。
```

## C

```text
带土：你今天又迟到两个小时。
卡卡西：路上扶老奶奶。
带土：哪条路？
卡卡西：木叶东门。
带土：我在神威里盯了两个小时。
卡卡西：你监视我？
带土：我在等你去给我上坟！
卡卡西：那墓地应该走西门。
```

## D

```text
大蛇丸：把身体交给我，你会获得永生。
佐助：你自己的呢？
大蛇丸：这副身体快到期限了。
佐助：你三年换一副，还敢跟我谈永生？
大蛇丸：那是不断进化。
佐助：连原装身体都保不住的人，离我的远点。
大蛇丸：你对永生是不是有误解？
佐助：你对自己的口碑有误解。
```

## E

```text
纲手：伤都好了，你还赖在医院干什么？
自来也：先占张床。
纲手：你又干什么了？
自来也：新书里写了你。
纲手：写我什么？
自来也：所以我才没退床。
纲手：挺有先见之明。
自来也：能换到离窗户近点吗？方便逃。
```

## F

```text
蝎：你为什么每次爆炸都叫我站最近？
迪达拉：艺术需要观众，嗯。
蝎：晓里那么多人。
迪达拉：他们看到一半就没了。
蝎：所以你选我？
迪达拉：你是唯一能看完的。
蝎：我是不死，不是免票。
迪达拉：那你想坐第一排还是站票？
```

## 人工反馈

- 最想继续看：B（比较有意思的一档）。
- 有意思：B、C、D、F。
- 无聊：A、E。
- 最好笑的一句：用户未指定。
- 从哪一句开始无聊：用户未指定。

## 校准结论

- 保留方向：黑色旧账、身份羞辱、危险关系中的主动权反转。
- B 最强原因：荒诞行为在第二句揭晓，鼬刚取得解释权，佐助立刻用灭族旧账把主动权打回去。
- C/D/F 的共同点：一方以原著身份占上风，另一方攻击其最脆弱的身份矛盾。
- A 无聊原因：冲突停留在小樱是否喜欢本体，损失偏轻，影分身没有带来更危险的新信息。
- E 无聊原因：自来也一开始已经知道会挨打，后续只是确认挨打，主动权没有真正翻面。
