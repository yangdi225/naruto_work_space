# S010 当佐助追问鼬当年为什么没追杀自己时

## 基础信息
- 时长：约 70 秒
- 使用公式：F008 旧账证据反杀 + F009 同词不同义误会升级
- 场景：宇智波旧址 / 月读空间
- 出场角色：佐助、鼬
- 核心冲突：佐助质问鼬为什么当年杀了全族却没有继续追杀自己，鼬用幻术回放证明佐助当年自己喊“别杀我”。
- 结尾反转：佐助本来想问出复仇理由，最后发现唯一知道自己黑历史的人就是鼬，于是复仇理由反而更充分了。

## 行为可信度自检
- 角色为什么会这么做：佐助为了复仇追问旧账；鼬为了压制和刺激佐助拿出幻术回放。
- 和原著身份/能力/关系的连接：宇智波兄弟、写轮眼、灭族夜、复仇执念全部直连原著。
- 去掉现代行政词后是否仍成立：成立，不依赖报告、请假、审批等现代流程。
- 证据道具是否围绕同一个核心误会：是，只围绕“为什么没追杀佐助”。
- 新加入角色是否让冲突升级：没有加入无关角色。
- 结尾是否是角色关系反杀，而不是流程处罚：是，佐助因为黑历史被鼬掌握而更想灭口。

## 进入脚本前确认
- 开场质问：佐助问鼬为什么杀了全族却没有追杀自己。
- 核心误会：佐助以为鼬不追杀是计划，鼬说是佐助当时哭着求别杀。
- 证据道具：写轮眼幻术回放。
- 嘴硬理由：佐助说那是战略性撤退，不是求饶。
- 二次打脸：幻术回放显示佐助不仅求别杀，还主动指了逃跑路线。
- 结尾补刀：佐助发现黑历史只有鼬知道，决定让鼬必须死。

## 对标节奏骨架
- 开场钩子：佐助带着复仇情绪质问鼬。
- 第一误会：佐助问“不追杀”背后的阴谋，鼬反问他是不是失忆。
- 第一证据/道具：鼬开启幻术回放灭族夜片段。
- 嘴硬辩解：佐助说自己当时是在保存战力。
- 第二证据/二次打脸：回放里小佐助边哭边给鼬指“你从那边走比较快”。
- 旁人补刀：鼬本人冷静补刀，说当时差点被笑到开不了眼。
- 结尾反杀：佐助说既然这事只有鼬知道，那鼬今天更不能活。

## 口播台词版

```text
佐助：鼬，我今天只问一件事。
鼬：你确定只问一件？
佐助：为什么你杀了全族，却没有追杀我？
鼬：你是不是失忆了？
佐助：别装傻。
鼬：我本来想给你留面子。
佐助：我不需要。
鼬：好。看这个。
佐助：你又想用幻术？
鼬：不是攻击，是回放。
佐助：回放什么？
鼬：灭族夜，你自己的原声。
佐助：......
鼬：你当时第一句是，哥哥别杀我。
佐助：那是战术。
鼬：第二句是，我还小，不好吃。
佐助：闭嘴，这不重要。
鼬：第三句是，你从后门走，追我比较绕。
佐助：我那是在误导你。
鼬：你一边误导，一边给我指了最近的门。
佐助：我当时年纪小。
鼬：所以我没追。
佐助：为什么？
鼬：你哭得太认真了。
佐助：......
鼬：我怕追上去，你再求一遍。
佐助：你少羞辱我。
鼬：我没有。全族就你一个活口，我总得保护一下笑点。
佐助：笑点？
鼬：那晚太沉重了，你算唯一的缓冲。
佐助：所以你留下我，是因为我好笑？
鼬：也可以说，因为你有潜力。
佐助：复仇的潜力？
鼬：不是，破防的潜力。
佐助：这件事还有谁知道？
鼬：暂时只有我。
佐助：那太好了。
鼬：好在哪里？
佐助：今天你必须死。
鼬：理由变了？
佐助：没变。只是更充分了。
```

## 角色站位
- 佐助站左侧，身体前压，手搭刀柄，情绪从冷到破防。
- 鼬站右侧，几乎不动，靠抬眼、闭眼、转身制造压迫。
- 幻术回放可用两人同时看向侧面空镜，或画面短暂变暗表示。
