# S011 当鸣人把通灵术当拉面配送用时

## 基础信息
- 时长：约 75 秒
- 使用公式：F002 忍术被当成职场工具 + F006 师徒互相甩锅 + F010 神级能力生活化误用
- 场景：木叶训练场
- 出场角色：鸣人、自来也、蛤吉
- 核心冲突：自来也发现鸣人频繁使用通灵术，以为他在刻苦训练，结果鸣人是让蛤吉从一乐带拉面过来。
- 结尾反转：鸣人说这是“实战型通灵训练”，蛤吉补刀说鸣人还让妙木山蛤蟆轮班排队。

## 行为可信度自检
- 角色为什么会这么做：鸣人训练时嘴馋，想偷懒吃一乐；自来也追责自己教的术被乱用；蛤吉被频繁叫来跑腿。
- 和原著身份/能力/关系的连接：鸣人爱拉面，自来也教通灵术，妙木山蛤蟆能被通灵到现场。
- 去掉现代行政词后是否仍成立：成立，不依赖审批、报告、请假。
- 证据道具是否围绕同一个核心误会：是，只围绕“通灵术到底是不是用来叫伙伴帮忙”。
- 新加入角色是否让冲突升级：蛤吉不是无关背锅，是被通灵术滥用的受害者。
- 结尾是否是角色关系反杀，而不是流程处罚：是，自来也追责鸣人，蛤吉反向揭穿鸣人更多滥用。

## 进入脚本前确认
- 开场质问：自来也质问鸣人为什么通灵卷轴上全是拉面油。
- 核心误会：鸣人认为通灵术就是需要帮忙时叫伙伴，自来也认为那是战斗支援。
- 证据道具：通灵卷轴油渍、蛤吉手里的拉面外带袋。
- 嘴硬理由：鸣人说这是“移动支援训练”，能锻炼通灵速度。
- 二次打脸：蛤吉说鸣人不是第一次，还让蛤蟆在一乐排队占座。
- 结尾补刀：自来也问鸣人有没有用通灵术救命，蛤吉说有，救过一碗快坨的面。

## 对标节奏骨架
- 开场钩子：自来也拿着沾油的通灵卷轴质问鸣人。
- 第一误会：鸣人说通灵术本来就是叫伙伴帮忙，自来也问帮什么忙。
- 第一证据/道具：蛤吉被通灵出来，手里拿着一乐拉面。
- 嘴硬辩解：鸣人说这是通灵速度训练。
- 第二证据/二次打脸：蛤吉揭穿鸣人让妙木山蛤蟆轮班排队。
- 旁人补刀：蛤吉说最离谱的是鸣人还要求“面硬一点”。
- 结尾反杀：自来也问有没有救命案例，蛤吉说救过快坨的面。

## 口播台词版

```text
自来也：鸣人，你先解释一下。
鸣人：解释什么？
自来也：通灵卷轴上为什么全是拉面油？
鸣人：训练辛苦，补充能量嘛。
自来也：你用通灵术补充能量？
鸣人：通灵术不就是需要帮忙时叫伙伴吗？
自来也：帮什么忙？
鸣人：帮我拿个面。
自来也：......
鸣人：热的。
自来也：你把妙木山蛤蟆当跑腿？
鸣人：那叫移动支援。
自来也：我教你通灵术，是让你战斗时保命。
鸣人：我也保命了啊。
自来也：哪次？
鸣人：饿死之前。
自来也：你别动，我重新理解一下。
鸣人：蛤吉！
蛤吉：来了。味噌拉面，加叉烧，少葱。
自来也：你还真送来了？
蛤吉：不是第一次了。
鸣人：蛤吉，你别乱说。
蛤吉：上次让我排队。
自来也：排队？
蛤吉：一乐门口，三只蛤蟆轮班。
鸣人：那是阵地轮换。
自来也：你管占座叫阵地轮换？
蛤吉：他还要求面硬一点。
鸣人：口感很重要。
自来也：鸣人，你知道通灵契约多神圣吗？
鸣人：所以我才没叫普通人。
自来也：你还挺尊重契约？
蛤吉：尊重。每次都让我把汤端稳。
自来也：我问最后一遍，你有没有用通灵术救过命？
鸣人：有。
自来也：谁的命？
蛤吉：一碗快坨的面。
鸣人：再晚十秒就不好吃了。
自来也：今天开始，你先别学忍术了。
鸣人：那学什么？
自来也：学会自己走去一乐。
```
