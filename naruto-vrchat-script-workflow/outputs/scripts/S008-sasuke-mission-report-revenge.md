# S008 当佐助把任务报告写成复仇宣言时

## 基础信息
- 时长：约 80 秒
- 使用公式：F004 第七班家庭会议 + F008 旧账证据反杀
- 场景：训练场
- 出场角色：小樱、佐助、鸣人、卡卡西
- 核心冲突：小樱要求佐助重写任务报告，因为他把普通护送任务写成了复仇宣言。
- 结尾反转：卡卡西以为自己能当和事佬，结果小樱发现鸣人的报告是影分身代写，卡卡西的评语也是复制粘贴。

## 进入脚本前确认
- 开场质问：小樱质问佐助为什么把护送任务写成“向世界复仇的第一步”。
- 核心误会：佐助觉得报告要写任务意义，小樱认为他在给火影办公室递战书。
- 证据道具：任务报告、鸣人的报告、卡卡西评语。
- 嘴硬理由：佐助说“这是任务精神总结”；鸣人说影分身代写也是本人意志；卡卡西说复制评语是教学效率。
- 二次打脸：报告里每段最后都写“终有一天我要复仇”；鸣人报告笔迹有 12 种。
- 结尾补刀：小樱说今天不是改报告，是第七班文化课重修。

## 对标节奏骨架
- 开场钩子：小樱拿着报告质问佐助。
- 第一误会：佐助以为小樱不理解任务精神，小樱说这是护送猫不是灭族复盘。
- 第一证据/道具：小樱念报告原文，每段都拐向复仇。
- 嘴硬辩解：佐助说复仇是他的写作风格。
- 第二证据/二次打脸：小樱拿出鸣人的报告，发现影分身代写，笔迹不统一。
- 旁人补刀：卡卡西想装老师，结果评语被发现每份都一样。
- 结尾反杀：小樱宣布第七班任务报告全员重写，卡卡西也要写。

## 口播台词版

```text
小樱：佐助，你先解释一下。
佐助：解释什么？
小樱：护送猫的任务报告，为什么标题叫《复仇，从今天开始》？
佐助：这是任务精神。
小樱：不是，这是火影办公室，不是你个人传记发布会。
佐助：你不懂。
小樱：我是不懂。你护送的是猫，不是宇智波族谱。
鸣人：噗。
佐助：你笑什么？
鸣人：没事，我只是觉得标题挺帅。
小樱：鸣人，你先别笑。你的报告也在这。
鸣人：我写得很认真啊！
小樱：第一行，天气晴。第二行，交给 3 号影分身写。
鸣人：那也是我本人意志！
小樱：第三行，3 号觉得麻烦，转交 8 号。
鸣人：团队协作嘛。
小樱：第六行，8 号下班了，报告由路过的影分身补完。
鸣人：影分身也是忍者！
佐助：哼，至少我的报告是本人写的。
小樱：你确定？
佐助：当然。
小樱：那你解释一下，为什么每一段最后都是“终有一天我要复仇”？
佐助：写作风格。
小樱：你管威胁村委会叫写作风格？
卡卡西：嘛嘛，年轻人有表达欲很正常。
小樱：卡卡西老师，你来得正好。
卡卡西：啊？
小樱：你给他们两个的评语，一字不差。
卡卡西：这只是老师的教学效率。
小樱：评语是“很有青春气息，继续保持”。
卡卡西：有什么问题吗？
小樱：佐助写复仇，鸣人没写完。你让谁保持？
卡卡西：......
鸣人：老师，你也被抓了。
佐助：无聊。
小樱：今天不是改报告。
鸣人：那是什么？
小樱：第七班文化课重修。你们三个，一个都跑不了。
卡卡西：我也要？
小樱：你评语写得像影分身代写的。
```

## 角色站位
- 小樱站正中，手拿三份任务报告，负责审判。
- 佐助站左侧，抱臂冷脸，报告被念到时侧头装没事。
- 鸣人站右侧，先看热闹，后被报告反杀。
- 卡卡西站后方树旁看书，中段插话，最后被小樱抓出来。
