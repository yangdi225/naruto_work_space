# S004 当带土提前看过剧本时

## 基础信息
- 时长：约 80 秒
- 使用公式：F011 预知剧本反向求生 + F008 旧账证据反杀
- 场景：神威空间 / 石柱平台
- 出场角色：带土、卡卡西、鸣人
- 核心冲突：带土提前看过“卡卡西嘴遁流程”，主动认错、主动交代、主动补偿，逼卡卡西找不到破防点。
- 结尾反转：卡卡西本来想讲道理，结果发现带土把自己所有台词都抢了，只能因为“抢台词”继续开打。

## 对标节奏骨架
- 开场钩子：带土拿着剧本慌了，说今天卡卡西会用三句话把自己说破防。
- 第一误会：卡卡西刚开口，带土以为他要走“琳、木叶、同伴”流程，直接跪下道歉。
- 第一证据/道具：带土拿出补偿清单：给琳立碑、给卡卡西补眼、给木叶写检讨。
- 嘴硬辩解：带土说这不是怕输，是“提前和解战术”。
- 第二证据/二次打脸：鸣人指出带土的检讨书只有第一页是道歉，后面全是月之眼招商计划。
- 旁人补刀：卡卡西发现带土不是真悔改，是把道歉也写成计划书。
- 结尾反杀：带土问自己为什么还要挨打，卡卡西说因为他把卡卡西的台词全抢了。

## 角色站位
- 带土站左侧，手里拿剧本和一沓补偿清单，时不时后退。
- 卡卡西站右侧，半侧身，手搭在护额旁，准备认真开口。
- 鸣人站中后方，拿着检讨书，负责拆穿和补刀。

## 封面标题建议
- 带土提前看剧本，卡卡西直接卡壳
- 带土主动认错后，为什么还是挨打？
- 无限月读招商计划被鸣人发现了

## 拍摄备注
- 单场景神威空间或任意暗色平台即可。
- 关键道具：剧本、补偿清单、检讨书。
- 带土语速要快，像急着把流程堵死。
- 卡卡西要慢，越被抢台词越无语。
- 鸣人负责翻文件补刀，镜头给纸张特写即可。
