# S009 当博人的请假条被鹿丸审出来是忍术代写时

## 基础信息
- 时长：约 75 秒
- 使用公式：F002 忍术被当成职场工具 + F008 旧账证据反杀
- 场景：火影办公室
- 出场角色：鹿丸、鸣人、博人、佐助
- 核心冲突：博人交请假条说自己查克拉感冒，鹿丸审出请假条是影分身、科学忍具和鸣人火影章共同完成的。
- 结尾反转：鸣人想教育博人，结果鹿丸发现鸣人的审批章也是影分身盖的。

## 进入脚本前确认
- 开场质问：鹿丸质问博人请假条上为什么有三种查克拉残留。
- 核心误会：博人以为请假条只要有火影章就算正规，鹿丸查的是“谁写的”。
- 证据道具：请假条、查克拉残留报告、火影章。
- 嘴硬理由：博人说这是团队协作；鸣人说火影章是真的就行；佐助说自己只是路过签了个证明。
- 二次打脸：鹿丸发现请假条是博人影分身起草、科学忍具润色、鸣人影分身盖章。
- 结尾补刀：鹿丸宣布父子俩一起补写检讨，题目叫《忍术不能用于请假流程》。

## 对标节奏骨架
- 开场钩子：鹿丸拿请假条问博人，查克拉感冒是什么病。
- 第一误会：博人以为鹿丸质疑病情，鹿丸说自己质疑的是请假条写作团队。
- 第一证据/道具：查克拉残留报告显示三个人参与。
- 嘴硬辩解：博人说多人协作提高效率，不叫作弊。
- 第二证据/二次打脸：火影章是真的，但盖章的是鸣人的影分身。
- 旁人补刀：佐助被牵出，证明他签字时根本没看内容。
- 结尾反杀：鸣人想教育博人，鹿丸让鸣人也一起写检讨。

## 口播台词版

```text
鹿丸：博人，你先解释一下。
博人：解释什么？
鹿丸：查克拉感冒是什么病？
博人：就是查克拉不舒服。
鹿丸：查克拉还能请病假？
博人：我爸是火影，他批了。
鸣人：咳，这个章确实是真的。
鹿丸：我没问章。我问谁写的。
博人：我写的啊。
鹿丸：那为什么有三种查克拉残留？
博人：现在写请假条也查查克拉？
鹿丸：麻烦死了，不查你能把村子请空。
博人：那叫流程优化。
鹿丸：第一种，博人的查克拉。
博人：看吧。
鹿丸：第二种，影分身的查克拉。
博人：影分身也是我。
鹿丸：第三种，科学忍具墨水。
博人：那叫排版。
鹿丸：你管作弊叫排版？
博人：至少内容真实。
鹿丸：内容写的是，因查克拉感冒，不能参加手里剑课。
博人：对啊。
鹿丸：下午你报名了雷遁实战体验。
博人：感冒不影响兴趣。
鸣人：博人，这就有点过分了。
鹿丸：七代目，你先别教育。
鸣人：啊？
鹿丸：火影章也有问题。
鸣人：章是真的啊！
鹿丸：章是真的，盖章的是你的影分身。
鸣人：那也是我本人意志！
博人：你看，我就说吧。
鹿丸：父子俩话术都一样，麻烦死了。
佐助：我只是路过。
鹿丸：你也别走。旁边还有你的签名。
佐助：我没看内容。
鹿丸：你签的是“本人确有病状”。
佐助：我以为是任务回执。
博人：所以我能请假吗？
鹿丸：能。
博人：真的？
鹿丸：请你们三个一起写检讨。
鸣人：我也要？
鹿丸：题目，《忍术不能用于请假流程》。
```

## 角色站位
- 鹿丸站办公桌左侧，手拿请假条和查克拉残留报告，负责审判。
- 博人站桌前，双手插兜，先嘴硬后心虚。
- 鸣人坐火影桌后，先帮腔，后被鹿丸反查。
- 佐助站门口或窗边，试图降低存在感，最后被签名牵出。
