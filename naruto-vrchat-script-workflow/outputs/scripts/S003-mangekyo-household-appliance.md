# S003 当佐助把万花筒玩成家电时

## 基础信息
- 时长：约 75 秒
- 使用公式：F010 神级能力生活化误用 + F008 旧账证据反杀 + F009 同词不同义误会升级
- 场景：宇智波旧址 / 训练场角落
- 出场角色：佐助、鼬、小樱
- 核心冲突：佐助质问鼬给的万花筒“质量不行”，鼬追问后发现佐助把天照、须佐、月读全当生活工具用。
- 结尾反转：小樱拿出医疗报告，证明佐助不是眼睛用坏了，是生活常识几乎没用过。

## 对标节奏骨架
- 开场钩子：佐助冲进来质问鼬，为什么万花筒不到一个月就开始花屏。
- 第一误会：鼬以为佐助经历高强度战斗，佐助说只是“正常生活使用”。
- 第一证据/道具：鼬拿出查克拉消耗报告，发现最大消耗地点是一乐后厨。
- 嘴硬辩解：佐助坚持“天照烧水效率高，须佐防风，功能差不多”。
- 第二证据/二次打脸：小樱拿出医疗报告，显示佐助把月读用于排队时“让自己感觉时间过得快一点”。
- 旁人补刀：小樱指出佐助不是复仇者，是把宇智波血继限界玩成家电测评。
- 结尾反杀：佐助说至少比鸣人聪明，小樱补刀：报告显示鸣人会用打火机。

## 角色站位
- 佐助站左侧，抱臂冷脸，开场直接前压。
- 鼬站右侧，背对佐助，听到“质量问题”后缓慢转身。
- 小樱站中后方，手拿医疗报告和查克拉消耗单，负责证据补刀。
