# S001 纲手让鸣人调查一乐叉烧失踪案

## 基础信息
- 时长：约 60 秒
- 使用公式：F001 离谱任务审判 + F008 旧账证据反杀
- 场景：火影办公室
- 出场角色：纲手、鸣人、卡卡西、小樱
- 核心冲突：鸣人觉得 S 级任务不该调查一乐叉烧，纲手坚持按村规立案。
- 结尾反转：真正偷叉烧的人是卡卡西，他用写轮眼复制了一乐优惠券，顺手把叉烧也“复制”走了。

## 角色站位
- 纲手坐办公桌后方，桌上放任务卷轴和一乐账单。
- 鸣人站桌前左侧，身体前倾，随时准备拍胸口争辩。
- 小樱站鸣人右后方，抱臂负责吐槽和压场。
- 卡卡西站门口右侧，低头看书，尽量降低存在感。
