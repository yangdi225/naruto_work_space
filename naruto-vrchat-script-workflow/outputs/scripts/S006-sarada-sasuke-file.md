# S006 当佐良娜要求公开佐助档案时

## 基础信息
- 时长：约 80 秒
- 使用公式：F013 英雄滤镜档案审判 + F008 旧账证据反杀
- 场景：火影办公室
- 出场角色：佐良娜、鸣人、鹿丸
- 核心冲突：佐良娜质问鸣人为什么封存佐助档案，鸣人不想说，鹿丸拿档案越翻越麻烦。
- 结尾反转：封档不是针对佐助，是为了让佐良娜还能正常上学。

## 对标节奏骨架
- 开场钩子：佐良娜冲进火影办公室，要求公开佐助档案。
- 第一误会：佐良娜以为鸣人针对佐助，鸣人说自己是在保护她。
- 第一证据/道具：鹿丸拿出封存档案，第一页就是“叛村记录”。
- 嘴硬辩解：佐良娜坚持那是忍者英雄的成长弯路。
- 第二证据/二次打脸：鹿丸继续翻出五影会谈、雷影、刺杀旧账。
- 旁人补刀：鸣人说档案不是不能公开，是公开后家长会没人敢坐她旁边。
- 结尾反杀：佐良娜感谢封档，但要求删掉“宇智波家庭风险提示”，鹿丸说那是她爸自己签的。

## 角色站位
- 鸣人坐办公桌后，表情为难。
- 佐良娜站桌前，抱臂质问。
- 鹿丸站侧边档案柜旁，拿文件夹，边翻边叹气。
