# S002 晓组织开会追责爆炸售后

## 基础信息
- 时长：约 65 秒
- 使用公式：F003 晓组织会议内耗 + F005 反派理念小题大做
- 场景：晓组织基地会议室
- 出场角色：小南、佩恩、迪达拉、鼬
- 核心冲突：小南发现晓组织经费全花在迪达拉的爆炸售后赔偿上。
- 结尾反转：鼬看起来最危险，却是唯一按时报销、还贴发票的人。

## 角色站位
- 佩恩站会议室正中央偏后，保持首领压迫感。
- 小南站左侧，手拿账本和报销单，负责审判。
- 迪达拉站右侧，手里举着黏土，越解释越破防。
- 鼬站最远处阴影里，抱臂沉默，偶尔抬眼。
