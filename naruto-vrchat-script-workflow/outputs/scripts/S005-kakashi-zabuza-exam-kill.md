# S005 当再不斩以为卡卡西靠考试杀穿晋升时

## 基础信息
- 时长：约 75 秒
- 使用公式：F009 同词不同义误会升级 + F008 旧账证据反杀
- 场景：雾隐桥边 / 训练场水边
- 出场角色：卡卡西、再不斩、鸣人
- 核心冲突：再不斩听说卡卡西小时候“杀人晋升”，以为木叶考试比雾隐还狠。
- 结尾反转：卡卡西说的是战场功勋，再不斩说的是毕业考试，最后鸣人发现再不斩还把隔壁考场也清了。

## 对标节奏骨架
- 开场钩子：再不斩质问卡卡西，木叶上忍是不是都靠考试杀穿晋升。
- 第一误会：卡卡西以为再不斩说忍战，再不斩以为卡卡西说考试。
- 第一证据/道具：鸣人拿出雾隐毕业档案，显示再不斩“考场清空”。
- 嘴硬辩解：再不斩说那叫效率，不叫违规。
- 第二证据/二次打脸：档案第二页显示他顺手清了隔壁考场。
- 旁人补刀：鸣人说这不是毕业，这是地图清怪。
- 结尾反杀：卡卡西承认自己战场杀敌，但再不斩考试杀同学更离谱。

## 角色站位
- 卡卡西站左侧，手拿亲热天堂，语气懒散。
- 再不斩站右侧，扛着斩首大刀，越聊越得意。
- 鸣人站中后方，拿着档案卷轴负责翻证据。
