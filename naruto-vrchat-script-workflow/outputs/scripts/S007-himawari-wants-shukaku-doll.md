# S007 当向日葵想要守鹤玩偶时

## 基础信息
- 时长：约 85 秒
- 使用公式：F014 真货误当玩具 + F009 同词不同义误会升级
- 场景：鸣人家客厅 / 木叶学校门口
- 出场角色：向日葵、鸣人、守鹤、同学
- 核心冲突：向日葵想要守鹤玩偶，鸣人以为“守鹤娃娃”就是守鹤本人，真把守鹤请来了。
- 结尾反转：同学以为向日葵买到高级会说话版本，结果砂隐压根没卖过，鸣人买的是本体。

## 对标节奏骨架
- 开场钩子：向日葵说同学都有守鹤娃娃，她也要一个。
- 第一误会：鸣人以为要真的守鹤，同学说的是普通周边玩偶。
- 第一证据/道具：鸣人把守鹤带回家，让守鹤打招呼。
- 嘴硬辩解：鸣人说“会说话说明质量好”。
- 第二证据/二次打脸：同学拿出普通玩偶，对比发现向日葵那个会骂九尾。
- 旁人补刀：守鹤自己声明“我不是玩偶，我是砂隐守鹤”。
- 结尾反杀：鸣人说至少孩子高兴，守鹤说他要收尾兽出场费。

## 角色站位
- 家中段：鸣人站沙发旁，向日葵站中间，守鹤站旁边或坐地上。
- 学校段：向日葵站前方炫耀，同学站对面，守鹤站她身后。
